# Definition of Done

A task is complete only when applicable items below are satisfied.

## Requirements

- [ ] Requirements understood.
- [ ] Acceptance criteria satisfied.
- [ ] Assumptions documented.

## Implementation

- [ ] Minimal change implemented.
- [ ] No unnecessary dependencies.
- [ ] No unrelated refactoring.

## Quality

- [ ] Formatting/linting passed.
- [ ] Type checking passed where applicable.
- [ ] Tests passed.
- [ ] Error handling reviewed.

## FinTech

- [ ] Monetary calculations use Decimal.
- [ ] Financial operations are idempotent where required.
- [ ] Financial state changes are auditable.
- [ ] Failures are observable and traceable.

## Security

- [ ] No secrets committed.
- [ ] Sensitive data handling reviewed.

## Operations

- [ ] Logging/observability considered.
- [ ] Deployment impact considered.
- [ ] Rollback/recovery considered.

## Documentation

- [ ] Important decisions documented.
- [ ] User-facing or operational documentation updated where necessary.
