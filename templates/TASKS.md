# TASKS / 项目任务计划

Use this file to maintain the project-level execution plan. TASK.md defines an individual task; TASKS.md defines the overall task hierarchy.
本文件用于维护项目级执行计划。TASK.md 定义单个任务；TASKS.md 定义整个项目的任务层级。

## 1. Planning Principles / 规划原则

- Epic → Feature → Task → Subtask / Epic → Feature → Task → Subtask
- One task should have a clear objective and acceptance criteria / 每个任务应有明确目标和验收标准
- Material architecture, financial, security, or regulatory decisions require ADR and human approval / 重大架构、金融、安全或监管决策必须进入 ADR 并经过人工审批
- Do not start substantial implementation before the project baseline is approved / 项目基线未批准前不得开始大量正式实现
